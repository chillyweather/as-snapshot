# MVP stores evidence notes, not copied source text

The MVP stores source URLs, metadata, concise Evidence Notes, and minimal factual snippets needed for traceability, but it does not store full page bodies, article text, reviews, copied book samples, or long excerpts in normal candidate records or extraction logs. This preserves enough evidence for editor review and debugging while reducing copyright and data-handling risk; later full-text workflows can use separate rules for uploaded text and quote/page citations.
