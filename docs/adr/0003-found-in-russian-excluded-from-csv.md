# Found in Russian candidates are excluded from the editor-facing CSV

The MVP excludes Scouting Candidates marked Found in Russian from the editor-facing weekly CSV instead of showing them as low-priority rows. They are still stored in Excluded Candidate History with identity, evidence, matching URL, exclusion reason, and date, so the system avoids rediscovery churn and can re-enter a candidate if new evidence changes the Russian-publication status. This keeps the acquisition watchlist focused on plausible open opportunities while preserving traceability.
