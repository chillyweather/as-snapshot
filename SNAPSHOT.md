# About this repository

This is a public snapshot of AutoScout, a private tool in weekly production use with a real book editor. It is regenerated automatically from the private repository on every change to `main`.

Source commit: `5e7398014f66425a0a7f4866d7dd2f0d2090f112`

To protect the editor's privacy, the snapshot leaves out live scouting state, the editor's decisions and notes, server operations, and the test fixtures and tests that depend on real editorial data (147 files). Quotes of the editor's notes elsewhere are replaced with `[editor note withheld]`. Everything else is copied as it is.

The live source configuration and the source research are also withheld, and test fixtures that hold licensed third-party content are left out with the tests that use them. This copy shows how the tool is built; it is not meant to run as it is.
